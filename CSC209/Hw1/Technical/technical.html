Relative URLs

A relative URL points to a file based on the location of the current webpage. For example, ../home.html tells the browser to go up one folder and open home.html. Relative URLs are useful for linking pages within the same website.

Absolute URLs

An absolute URL includes the complete web address, such as https://www.w3schools.com/. Absolute URLs are usually used when linking to a different website or an external page.
